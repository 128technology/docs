<!---7.0.1 Conductor Upgrade Note --->

:::important
**7.x Conductor Upgrades**

If you are upgrading a **conductor** that currently running version 6.3.4 or lower, and you wish to upgrade any version 7.x or higher, you must first upgrade the conductor to version 6.3.5.

Once the conductor has completed the 6.3.5 installation, you may upgrade to any 7.x version of the SSR software.

If your conductor is currently running SSR version 6.3.5+, you may upgrade to 7.0.1 normally.

**Conductor-managed routers that are being upgraded to 7.x DO NOT have to make a transitional installation step to communicate with a conductor running 7.0.1+. Router upgrades can go directly from pre-7.x to 7.x.**

Conductor-managed routers running SSR software versions earlier than 6.3.5 do not have to be upgraded, although it is highly recommended to have devices running fully supported software versions. 
:::
